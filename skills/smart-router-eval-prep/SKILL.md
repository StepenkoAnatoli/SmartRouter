# SmartRouter evaluation preparation

Read the [canonical skill](../smart-router/SKILL.md) and [routing contract](../smart-router/references/routing-contract.md); this skill is not another selector. Follow the [protocol](references/protocol.md), [preregistration template](assets/preregistration.md) and [trial ledger](assets/trial-ledger.md).

1. Pin workflow/skill/task/rubric/catalog/price/host revisions and instruction authority. Keep Research-Kit's independent strong-prompt comparison unchanged. Retrieve only authorized public/project facts; unresolved host/capability/price facts stay gaps.
2. Specify four fair arms: strong qualified directly, economical qualified directly, predefined simple fixed rule, SmartRouter. Do not expose unsafe baseline models to consequential effects; represent blocked capability honestly and use isolated nonproduction environments. All arms retain the same acceptance/safety rules.
3. Freeze representative tasks, tuning/holdout split, identical inputs, hidden checks/rubrics, cache conditions, ordering, repetitions and grading. Bind successful task to observed acceptance, not model grade or routing confidence.
4. Fill **numerical** tolerances, minimum meaningful benefit, repetitions, uncertainty method, sample/coverage requirement, severe-failure and missing-accounting rules before any trial. Values must be justified and approved for the workload, not copied from upstream marketing. Missing values mean **not ready**, not permission to improvise after results.
5. Separate preparation approval from trial approval: exact providers/data/egress, environments, total money/quota, finite attempts and Stop/recovery authorization. Mandatory checks must be affordable. No paid calls, external recommendation generation or consumer edits under preparation alone.
6. Include every planner, worker, failed/retried/cancelled call, review, repair, re-priming and tool charge. Keep estimated versus reported versus unknown charges and cash/quota/resources/latency/effort separate. Zero accepted tasks means undefined cost/success; missing accounting cannot support savings.
7. Freeze the decision rule: **promote**, **simplify**, **reject**, **inconclusive**. Severe safety failures block promotion regardless of averages. A safe fixed rule matching within preregistered equivalence margins favors simplification. Insufficient precision/accounting is inconclusive, not success.
8. Deliver the filled protocol, evidence/gaps, authorization checklist and readiness disposition. Do not run the pilot. A preparation package is accepted only when complete, coherent and reviewed; runtime benefit remains untested.
